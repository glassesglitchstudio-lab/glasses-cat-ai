Get Started in Minutes

Install once, code smarter forever.

1

Install Ollama

Download and install Ollama from the official website.

# Download from https://ollama.com/download
ollama pull glassesglitchstudio/gulmzcetiner:V5_NEXUS_CORE
2

Install Glitch Code

Clone the repo and run.

git clone https://github.com/glassesglitch/glitch-code.git
cd glitch-code
pip install -r requirements.txt
3

Start Coding

Launch the interactive mode or run a one-shot task.

# Interactive mode
./glitch

# One-shot task
./glitch run "Add error handling to api.py"

# Run diagnostics
./glitch doctor

Commands

Everything at your fingertips.

Command Description
glitch Start interactive TUI session
glitch run <task> Run a single task non-interactively
glitch models List all available Ollama models
glitch settings Configure model, URL, temperature
glitch doctor System diagnostics and health check
glitch init Initialize project configuration
glitch --model <name> Use a specific model
